Roon AI

Welcome! This installer will set up Roon AI on your Mac.

What gets installed:

• /usr/local/bin/roon-ai - The application
• LaunchDaemon - Runs automatically at startup
• Web UI - Available at http://localhost:8088

Features:

• Conversational AI control of your Roon zones
• Voice in/out with streaming responses
• Web UI with multi-conversation history
• Claude AI integration via MCP
